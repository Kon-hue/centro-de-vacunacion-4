Arquitectura y Desarrollo Frontend

Sistema Nacional de Vacunación

Guía de Ingeniería Paso a Paso: Diseño, Componentes, Estado y Lógica en React
Stack: React 19 + JavaScript + CSS Moderno Enfoque: 100% Frontend (Arquitectura por Capas) Nivel: De Fundamentos a Proyecto Profesional

1. ¿Qué es y qué problemas resuelve este sistema?

Un Sistema de Vacunación Nacional es una plataforma pública y hospitalaria crítica. Desde la perspectiva de Frontend, debe resolver tres necesidades operativas con la máxima usabilidad, claridad y velocidad de respuesta:

  • Portal Ciudadano (Consulta de Carnet Digital): Permite a cualquier habitante consultar su historial oficial de dosis aplicadas buscando por documento de identidad (DNI/Cédula), ver su estado (esquema completo o incompleto) y generar su certificado.
  • Agendamiento de Citas: Permite reservar turno seleccionando centro de vacunación, tipo de vacuna (COVID-19, Influenza, Hepatitis B, etc.), fecha y franja horaria disponible.
  • Módulo de Registro Clínico (Personal Sanitario): Formulario rápido para que el enfermero/vacunador registre la aplicación en tiempo real (lote de vacuna, fecha, centro de salud y observaciones).
  • Tablero Estadístico (Dashboard): Métricas visibles de dosis aplicadas, porcentaje de cobertura y stock estimado.
💡 ¿Por qué enfocarse primero en el Frontend?
Construir primero el Frontend con datos simulados (Mock Data) y estado local permite validar toda la experiencia de usuario (UX), definir exactamente qué datos viajarán en la API y tener un prototipo 100% interactivo y visual antes de configurar servidores o bases de datos complejas.

4. Componentes Clave: Código y el "Por Qué" de Cada Línea

A. Barra de Navegación con Pestañas (Navbar.jsx)

Permite alternar entre las diferentes vistas de la aplicación sin recargar la página: 

// src/components/Navbar.jsx
import React from 'react';

export default function Navbar({ pestanaActiva, setPestanaActiva }) {
  const enlaces = [
    { id: 'dashboard', texto: '📊 Panel General' },
    { id: 'consulta', texto: '🔍 Consulta Ciudadana' },
    { id: 'citas', texto: '📅 Agendar Cita' },
    { id: 'registro', texto: '💉 Registro de Dosis' }
  ];

  return (
    <header className="header-nav">
      <div className="brand">
        <span className="flag-icon">🏛️</span>
        <div>
          <h1 className="brand-title">SISNAV</h1>
          <span className="brand-sub">Sistema Nacional de Vacunación</span>
        </div>
      </div>
      <nav className="nav-buttons">
        {enlaces.map((enlace) => (
          <button
            key={enlace.id}
            className={`nav-btn ${pestanaActiva === enlace.id ? 'active' : ''}`}
            onClick={() => setPestanaActiva(enlace.id)}
          >
            {enlace.texto}
          </button>
        ))}
      </nav>
    </header>
  );
}

El porqué: En lugar de instalar dependencias externas de enrutamiento al comenzar, usamos un estado pestanaActiva en el componente padre. Al hacer clic en un botón, se actualiza el estado y React renderiza la vista solicitada de forma instantánea.

B. Módulo de Consulta Ciudadana y Carnet Digital (ConsultaView.jsx)

Esta es la interfaz que usará el público general. Recibe el listado completo de registros y filtra por DNI: 

// src/views/ConsultaView.jsx
import React, { useState } from 'react';

export default function ConsultaView({ registros }) {
  // 1. Estados locales para el input de búsqueda y el resultado
  const [busquedaDni, setBusquedaDni] = useState('');
  const [pacienteConsultado, setPacienteConsultado] = useState(null);
  const [historialEncontrado, setHistorialEncontrado] = useState([]);
  const [haBuscado, setHaBuscado] = useState(false);

  // 2. Función que ejecuta el filtro cuando se presiona Buscar
  const handleBuscar = (e) => {
    e.preventDefault();
    const dniLimpio = busquedaDni.trim();
    if (!dniLimpio) return;

    // Filtramos los registros que coincidan exactamente con el DNI
    const resultados = registros.filter(r => r.dni === dniLimpio);

    setHistorialEncontrado(resultados);
    setHaBuscado(true);

    if (resultados.length > 0) {
      setPacienteConsultado(resultados[0].paciente);
    } else {
      setPacienteConsultado(null);
    }
  };

  return (
    <div className="view-container">
      <div className="card search-card">
        <h2>Consulta de Carnet Oficial de Vacunación</h2>
        <p>Ingresa tu número de documento de identidad para verificar tus dosis registradas.</p>
        
        <form onSubmit={handleBuscar} className="search-form">
          <input
            type="text"
            placeholder="Ej: 12345678"
            value={busquedaDni}
            onChange={(e) => setBusquedaDni(e.target.value)}
            className="input-field"
            required
          />
          <button type="submit" className="btn btn-primary">
            Consultar Carnet
          </button>
        </form>
      </div>

      {/* 3. Renderizado condicional según el resultado */}
      {haBuscado && historialEncontrado.length > 0 && (
        <div className="card carnet-digital">
          <div className="carnet-header">
            <div>
              <span className="badge badge-success">✓ Registro Oficial Activo</span>
              <h3 className="patient-name">{pacienteConsultado}</h3>
              <p className="patient-dni">Documento: {busquedaDni}</p>
            </div>
            <div className="qr-simulado">[QR Verificación]</div>
          </div>

          <table className="table-carnet">
            <thead>
              <tr>
                <th>Vacuna</th>
                <th>Dosis</th>
                <th>Fecha</th>
                <th>Lote</th>
                <th>Establecimiento</th>
              </tr>
            </thead>
            <tbody>
              {historialEncontrado.map((item) => (
                <tr key={item.id}>
                  <td><strong>{item.vacunaNombre}</strong></td>
                  <td>Dosis #{item.dosisNumero}</td>
                  <td>{item.fechaAplicacion}</td>
                  <td><code>{item.lote}</code></td>
                  <td>{item.centroSalud}</td>
                </tr>
              ))}
            </tbody>
          </table>
        </div>
      )}

      {haBuscado && historialEncontrado.length === 0 && (
        <div className="callout" style={{ background: '#fff1f2', borderColor: '#e11d48' }}>
          <div className="callout-title" style={{ color: '#9f1239' }}>No se encontraron registros</div>
          No se encontró ninguna dosis aplicada al DNI <strong>{busquedaDni}</strong>.
        </div>
      )}
    </div>
  );
}

C. Módulo del Vacunador / Registro Clínico (RegistroView.jsx)

Este módulo permite al personal de salud registrar una nueva dosis aplicada. Utiliza un formulario controlado con validaciones: 

// src/views/RegistroView.jsx
import React, { useState } from 'react';

export default function RegistroView({ catalogoVacunas, centrosSalud, onRegistrarDosis }) {
  // Estado único para agrupar los campos del formulario
  const [form, setForm] = useState({
    dni: '',
    paciente: '',
    vacunaId: catalogoVacunas[0]?.id || '',
    dosisNumero: 1,
    fechaAplicacion: new Date().toISOString().split('T')[0],
    lote: '',
    centroSalud: centrosSalud[0]?.nombre || '',
    vacunador: ''
  });

  const [mensajeExito, setMensajeExito] = useState(false);

  // Manejador genérico para cualquier cambio de campo
  const handleChange = (e) => {
    const { name, value } = e.target;
    setForm(prev => ({ ...prev, [name]: value }));
  };

  const handleSubmit = (e) => {
    e.preventDefault();
    const vacunaSeleccionada = catalogoVacunas.find(v => v.id === form.vacunaId);
    
    // Creamos el nuevo registro
    const nuevoRegistro = {
      ...form,
      id: 'REG-' + Date.now(),
      vacunaNombre: vacunaSeleccionada ? vacunaSeleccionada.nombre : form.vacunaId,
      dosisNumero: Number(form.dosisNumero)
    };

    onRegistrarDosis(nuevoRegistro);
    setMensajeExito(true);

    // Limpiamos los campos clave tras el registro
    setForm(prev => ({
      ...prev,
      dni: '',
      paciente: '',
      lote: '',
      vacunador: ''
    }));

    setTimeout(() => setMensajeExito(false), 4000);
  };

  return (
    <div className="view-container">
      <div className="card">
        <h2>Registro de Aplicación de Vacuna</h2>
        <p>Formulario oficial para el personal de enfermería y vacunación.</p>

        {mensajeExito && (
          <div className="callout">
            <div className="callout-title">✓ ¡Dosis Registrada con Éxito!</div>
            La vacuna ha sido incorporada al historial clínico del ciudadano.
          </div>
        )}

        <form onSubmit={handleSubmit} className="grid-form">
          <div className="form-group">
            <label>DNI / Identificación del Paciente</label>
            <input
              type="text"
              name="dni"
              value={form.dni}
              onChange={handleChange}
              required
              placeholder="Número de cédula o DNI"
            />
          </div>

          <div className="form-group">
            <label>Nombre Completo del Paciente</label>
            <input
              type="text"
              name="paciente"
              value={form.paciente}
              onChange={handleChange}
              required
              placeholder="Ej: Sofía Ramírez"
            />
          </div>

          <div className="form-group">
            <label>Tipo de Vacuna (Biológico)</label>
            <select name="vacunaId" value={form.vacunaId} onChange={handleChange}>
              {catalogoVacunas.map(v => (
                <option key={v.id} value={v.id}>{v.nombre} ({v.fabricante})</option>
              ))}
            </select>
          </div>

          <div className="form-group">
            <label>Número de Dosis</label>
            <input
              type="number"
              name="dosisNumero"
              min="1"
              max="5"
              value={form.dosisNumero}
              onChange={handleChange}
              required
            />
          </div>

          <div className="form-group">
            <label>Lote de Vacuna</label>
            <input
              type="text"
              name="lote"
              value={form.lote}
              onChange={handleChange}
              required
              placeholder="Ej: LOTE-2026-X7"
            />
          </div>

          <div className="form-group">
            <label>Centro de Salud</label>
            <select name="centroSalud" value={form.centroSalud} onChange={handleChange}>
              {centrosSalud.map(c => (
                <option key={c.id} value={c.nombre}>{c.nombre}</option>
              ))}
            </select>
          </div>

          <button type="submit" className="btn btn-primary" style={{ gridColumn: 'span 2' }}>
            Guardar y Certificar Dosis
          </button>
        </form>
      </div>
    </div>
  );
}

5. El Componente Central: App.js y Persistencia

En App.js orquestamos todo el estado de la aplicación. Para que los registros ingresados no se borren cuando el usuario recargue la página en el navegador, utilizamos localStorage: 

// src/App.js
import React, { useState, useEffect } from 'react';
import Navbar from './components/Navbar';
import DashboardView from './views/DashboardView';
import ConsultaView from './views/ConsultaView';
import CitasView from './views/CitasView';
import RegistroView from './views/RegistroView';
import { CATALOGO_VACUNAS, CENTROS_SALUD, REGISTROS_INICIALES } from './data/initialData';
import './App.css';

function App() {
  const [pestanaActiva, setPestanaActiva] = useState('dashboard');

  // Inicializamos el estado cargando de localStorage o con los datos por defecto
  const [registros, setRegistros] = useState(() => {
    const guardados = localStorage.getItem('SISNAV_REGISTROS');
    return guardados ? JSON.parse(guardados) : REGISTROS_INICIALES;
  });

  // Cada vez que 'registros' cambie, lo guardamos automáticamente
  useEffect(() => {
    localStorage.setItem('SISNAV_REGISTROS', JSON.stringify(registros));
  }, [registros]);

  // Función para agregar un nuevo registro
  const handleRegistrarDosis = (nuevo) => {
    setRegistros(prev => [nuevo, ...prev]);
  };

  return (
    <div className="app-layout">
      <Navbar pestanaActiva={pestanaActiva} setPestanaActiva={setPestanaActiva} />

      <main className="main-content">
        {pestanaActiva === 'dashboard' && (
          <DashboardView registros={registros} catalogoVacunas={CATALOGO_VACUNAS} />
        )}
        {pestanaActiva === 'consulta' && (
          <ConsultaView registros={registros} />
        )}
        {pestanaActiva === 'citas' && (
          <CitasView centrosSalud={CENTROS_SALUD} catalogoVacunas={CATALOGO_VACUNAS} />
        )}
        {pestanaActiva === 'registro' && (
          <RegistroView
            catalogoVacunas={CATALOGO_VACUNAS}
            centrosSalud={CENTROS_SALUD}
            onRegistrarDosis={handleRegistrarDosis}
          />
        )}
      </main>
    </div>
  );
}

export default App;

6. Resumen de Buenas Prácticas Aplicadas

Concepto Dónde se aplica Beneficio Técnico
Lazy Initial State useState(() => localStorage...) Evita leer el disco en cada render; solo se lee una vez al cargar la web.
Inmutabilidad del Estado setRegistros(prev => [nuevo, ...prev]) React detecta el cambio de referencia y re-renderiza eficientemente la tabla.
Formularios Controlados value={form.campo} onChange={...} React es la única fuente de verdad; previene inconsistencias entre el DOM y los datos.
Componentes Puros Navbar, StatCard Fáciles de testear y reutilizar en cualquier parte del sistema.
